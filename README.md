# leetneetcode

This repository contains Java solutions and JUnit tests for a curated set of coding problems (IBM Top50 / LeetCode-style). Each solution lives under `src/main/java/com/ibm` and tests under `src/test/java/com/ibm`.

Run tests:

```bash
mvn -DskipTests=false test
```
